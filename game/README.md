# 時の封土 ― 現代ブラウザ移植版

1990年代に制作された「時の封土」を、現在のWebブラウザで遊べるよう再構築したノベルアドベンチャーゲームです。原作版の4:3表示と、画像・画面構成を刷新したリメイク版の16:9表示を切り替えられます。

## 動作環境

- Windows 10／11
- 現行版のGoogle Chrome、Microsoft Edgeなどのモダンブラウザ
- Python 3（未導入の場合は起動時に自動インストールを案内します）
- 音声を再生できるサウンド環境

ゲームはローカルWebサーバーを介して起動します。`index.html`を直接ダブルクリックしても正常には動作しません。

## インストール

1. GitHub Releasesから最新版のZIPファイルをダウンロードします。
2. ZIPファイルを任意のフォルダへ展開します。
3. 展開したフォルダにある`start-server.cmd`を実行します。

Python 3が未導入の場合は、インストールするかどうかの確認が表示されます。`Y`を選ぶと、Windows Package Manager（`winget`）を使用して現在のWindowsユーザー用にPythonを導入します。管理者権限を要求せずに導入できる構成です。

`winget`が利用できない場合や自動インストールに失敗した場合は、Python公式ダウンロードページが開きます。その場合は手動でPython 3をインストールし、`Add Python to PATH`を有効にしてから`start-server.cmd`をもう一度実行してください。

フォルダ名や展開先は自由です。クラウド同期フォルダでも動作しますが、同期中にゲームファイルやセーブデータを同時編集しないでください。

## 起動方法

展開したフォルダにある`start-server.cmd`をダブルクリックします。

ローカルサーバーが起動し、ブラウザが自動的に開きます。初回起動時に、その展開先専用の空いているポート番号が割り当てられます。

割り当てられた番号はゲームフォルダの`.time2-port`に記録され、次回以降も同じ番号を使用します。別のフォルダへ展開したゲームとはブラウザ保存領域が分離されるため、既読情報、設定、達成状況などが意図せず混ざりません。

ゲームのタブを閉じると、約15秒後にサーバーも自動終了します。手動で終了する場合は、サーバーのコマンドプロンプトで`Ctrl+C`を押してください。

### 手動起動

PowerShellまたはコマンドプロンプトでゲームのフォルダへ移動し、次を実行します。

```powershell
python server.py
```

特定のポートを使用する場合は、次のように指定できます。

```powershell
python server.py --port 8127
```

## ゲームの始め方

初回起動時に音声再生の確認画面が表示されます。BGM、ボイス、効果音を使用する場合は音声を有効にしてください。

- **初めから**：シナリオの最初から開始します。
- **続きから**：セーブデータを選んで再開します。
- **おまけ**：いずれかのエンディング達成後に追加されます。

エンディングの達成状況に応じて、エンディングリプレイ、ギャラリー、音楽、特別付録などが開放されます。

## 基本操作

| 操作 | マウス／タッチ | キーボード |
|---|---|---|
| メッセージを進める | 画面をクリック／タップ、ホイールを下へ | テンキー`0` |
| メッセージ・選択肢を一時的に隠す | 右クリック | `Esc` |
| テキスト履歴を開く | ホイールを上へ | ― |
| 選択肢を決定する | 選択肢をクリック／タップ | カーソルキーと決定キー |
| 高速スキップ | ― | `Ctrl`を押している間 |
| ポップアップを閉じる | 右クリック、枠外をクリック | `0`または`Esc`（画面による） |

ボイスが設定されたセリフは、本文をクリックすると再度再生できます。テキスト履歴内の対応するセリフからも再生できます。

画面下部のメニューから、セーブ、ロード、スキップ、アイテム、設定を利用できます。場面やモードによって使用できない項目は非表示になります。

## セーブデータ

- セーブスロットは60個です。
- セーブ内容はゲームフォルダ直下の`save-data.json`に保存され、ブラウザ内にも動作用キャッシュが作成されます。両者が異なる場合は`save-data.json`が優先されます。
- `save-data.json`をバックアップすると、セーブデータを保管できます。
- ゲームの実行中や保存中に`save-data.json`を編集・置換しないでください。
- 古いHTMLシナリオ版のセーブデータとは互換性がありません。

ゲームフォルダを移動するときは、セーブデータを引き継ぐ場合だけ`save-data.json`と`.time2-port`も一緒に移動してください。新規プレイ用として別フォルダへ展開する場合は、この2ファイルをコピーしないでください。

## 設定

設定画面では、主に次の項目を変更できます。

- 原作版／リメイク版
- BGM、ボイス、システム効果音、シナリオ効果音の音量とミュート
- フォントサイズ
- 画像切替エフェクト
- 未読部分をスキップするかどうか

原作版は4:3、リメイク版は16:9で表示されます。リメイク版に対応画像がない場合は、利用可能な原作版画像へ自動的に切り替わることがあります。

## 主なフォルダ

- `index.html`：ゲームの起動ページ
- `server.py`：ローカルサーバーとセーブ管理
- `scenario/`：シナリオ、アイテム、ギャラリー、音楽、スタッフロールなどの定義
- `html/`：ゲーム画面の部品
- `js/`：シナリオエンジン、描画、セーブ処理
- `resource/original/`：原作版画像
- `resource/remake/`：リメイク版画像
- `mp3/`：BGM
- `voice/`：ボイス
- `se/`：システム効果音・シナリオ効果音

## トラブルシューティング

### Pythonが見つからない

Python 3をインストールし、コマンドプロンプトで次が実行できることを確認してください。

```powershell
python --version
```

### 404 File not foundになる

`index.html`を直接開かず、必ず`start-server.cmd`または`python server.py`から起動してください。

### 音が鳴らない

- 起動直後の音声確認で音声を有効にしてください。
- 設定画面の各音量とミュートを確認してください。
- ブラウザやOS側の音量設定も確認してください。

### 変更した音声や画像が反映されない

ゲームのタブを閉じてサーバーが終了したことを確認し、再起動してください。それでも変わらない場合は、ブラウザのキャッシュを消去して再読み込みしてください。
